# TAMA INDEX

An independent, research-led Tamagotchi reference index with an editorial interface from Cut State.

## Run locally

Open `index.html` in a browser. No build chain or third-party runtime is required.

## Editorial rule

TAMA INDEX is not a type foundry. It is an independent Tamagotchi research wiki. Cut State provides the visual system and editorial direction.

## Research refresh

The current site data and source ledger were refreshed 2026-09-18. See `docs/research-ledger.md` and `data/current-brief.json`.

The interface uses original CSS/SVG-like geometric artwork rather than unlicensed franchise imagery. Tamagotchi is a Bandai trademark; TAMA INDEX is unofficial and independent.
