# TAMA INDEX

TAMA INDEX is an independent, citation-led Tamagotchi research index and editorial wiki. It documents devices, eras, care systems, characters, officially released resources, and news with a clear separation between verified facts, community references, and items awaiting confirmation.

CUT STATE is the independent type foundry and visual direction behind the project. It is not the subject of this archive.

## Launch foundation

- `index.html` — original, image-light editorial landing page
- `assets/` — original visual assets and stylesheet
- `docs/launch-docket.md` — today’s launch docket, editorial system, and research standards
- `data/model-index.csv` — starter structured index for source-led expansion
- `docs/source-register.md` — initial source register and verification protocol

## Editorial and rights standard

TAMA INDEX uses original diagrams and typography-led compositions where possible. Official materials are linked to their source. Third-party fan resources are catalogued through attribution and outbound links; unlicensed imagery, scans, and downloadable files are not reproduced.

## Current scope

The first release establishes the research system and public front door. Model coverage is intentionally marked by verification status rather than implying completeness.
